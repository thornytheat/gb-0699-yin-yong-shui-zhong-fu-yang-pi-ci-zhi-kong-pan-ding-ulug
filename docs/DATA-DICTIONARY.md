# 饮用水批次质控定义

id保留前导零；batch+analyte+pair决定平行样配对。kind为sample、duplicate、spike、blank。浓度单位mg/L、ug/L统一为mg/L；数值用Decimal。检出限Pb、As均为0.001mg/L，限定值形式<0.001不按零处理。

均值低于5倍检出限时，平行样采用绝对差<=检出限；其余采用差值/均值<=20%。双零通过绝对差规则。加标回收=(加标样-本底)/加标量×100%，80—120%通过；加标量非正失败。空白严格超过检出限才判污染。

同id最高version为生效复测，同版本重复隔离。放行优先级为空白污染、空白缺失、回收失败、加标异常、配对失败、限定值复核。每个批次每项必须有空白；受限值进入人工复核。失败检测批生成逐样复测任务和下一最低版本。

复测采用batch+analyte+id作为身份键，在此身份内选择最高version；不同检测项允许复用同样品编号。

## 证据谱系（M8）

每条质控结论（平行/回收/空白）按物理行号锚定其引用的测量，同集合生成证据组号（如 L2-4）。同一测量行被多于一类质控引用即为共享测量：实验台把一支平行样同时登记为加标本底时，平行结论与回收结论共享该次测量，标记 shared_evidence，不得计为两次独立证明。空白、平行复测样、加标样等只服务单一结论的测量计入独立测量。

同 pair 出现多支 sample 时，最早登记的一支固定为平行核对成员，其余为补入的独立测量；加标回收优先选用未被平行核对占用的独立本底（independent_base=true），无独立本底时才沿用共享本底。补样不改变原配对的成员与结论。

## 版本化补样

补入独立样生成新数据版本（data_version 递增，parent_version 指向上一版）；run_versions 只追加保存每版全文、摘要与受影响结论 affected，runs 表为当前版本指针。复核流水 review_revision 与数据版本各自独立；补样后决定重置为待复核。同补充内容按 extra_digest 幂等。
